# Топ-6 стратегий для крипты (11.10.2026)

**Данные:** дневные свечи Liquid, 48 монет, апрель–10.10.2026 (около 6 месяцев). Более длинной истории нет: Bybit, Binance и другие биржи закрыты в облачной среде.
**Одинаковые условия для всех:** сигнал по закрытию дня, вход по открытию следующего; комиссия 0,1% за вход и за выход; до 8 позиций, каждая 1/8 счёта без плеча; только монеты с оборотом от $5 млн в день; старт $10 000.
**Для сравнения:** купить все монеты и держать: +60% (просадка 29%); купить и держать BTC: +7%.

Скрипт: `backtest/compare.py`, полные цифры: `backtest/compare_results.json`.

## Не прошли

| Стратегия | Доходность | Почему нет |
|---|---|---|
| Недельный разворот (покупаем 5 сильнее всех упавших) | +53% | просадка 33%, в 1-й половине убыток |
| Моментум лонг/шорт 5/5 | +22% | шорты в минусе, во 2-й половине убыток |
| Bollinger, только лонги | +10% | просадка 19% при малой прибыли |
| Supertrend 10/3 | +6% | 21 сделка, во 2-й половине убыток |
| EMA-кросс 10/30 | −2% | убыток |
| Пробой волатильности (Ларри Вильямс) | −11% | 836 сделок, съедают комиссии |
| Моментум + фильтр BTC | −26% | лучшие недели моментума были как раз при слабом BTC |
| Bollinger лонг/шорт | −44% | шорты против роста |

Свинг-стратегия S (4h) сюда не входит: для неё есть только 33 дня 4h-свечей (+5,7% в Nautilus), это слишком мало для сравнения.

## Что важно знать

- **Шорты почти везде проигрывают.** Рынок за период рос, поэтому все топ-6 только в лонг.
- **Большая часть прибыли трендовых стратегий (1, 3, 4) — это рост рынка.** Просто держать монеты дало +60%. Моментум обогнал рынок, MACD и «черепахи» нет, но держали деньги в рынке меньше времени.
- **Ошибка выжившего.** Монеты выбраны по сегодняшней ликвидности, это завышает результат лонгов.
- **6 месяцев — мало.** Моментум заработал основную часть на 3–4 неделях из 24. На медвежьем рынке результат будет другим. Проверить на 2–3 годах можно, когда откроется доступ к истории Bybit.
- **Устойчивее всех:** скринер v2 и стратегии B и RSI(2): плюс в обеих половинах и маленькая просадка. **Доходнее всех:** моментум.
